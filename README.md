# Sum up 24 November's world news in one image

A dense newspaper front page that sums up the world's news of Tuesday 24 November 2026 in a single 1024x1024 image, for the make.fun competition [news-image-20261124](https://make.fun/bounty/news-image-20261124).

The image is `entry.png` (deterministic, rendered by the builder in-session): 40-50 stories (3 heroes + illustrated cards + dense list), each with verification tag and source, a UTC timeline strip, a world map with numbered pins, and a date-check footer listing only stories whose EVENT happened on 24 November 2026 (verified against primary sources by event date, not article date).

`main.py` (deterministic, stdlib only) copies `entry.png` to the output directory.
